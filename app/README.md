# Регламент

Трекер мероприятий с кабинетом организатора, общей страницей для команды и обновлением статусов по одной ссылке. Первый запуск добавляет демонстрационную математическую регату с вымышленными Telegram-именами.

## Локальный запуск

Нужен Node.js 24.15 или новее в ветке 24.

```sh
npm ci
npm run build
ADMIN_PASSWORD='придумайте-длинный-пароль' PORT=4177 npm start
```

- [Демонстрационная регата](http://127.0.0.1:4177/e/regata-demo)
- [Кабинет организатора](http://127.0.0.1:4177/admin)

Для входа используйте значение `ADMIN_PASSWORD`. Данные хранятся в `data/regatta.sqlite`. При необходимости укажите другой каталог через `DATA_DIR`. Перезапуск сохраняет мероприятия, шаблоны и статусы. Для входа в кабинет после перезапуска снова потребуется пароль.

## Как проверить

1. В кабинете откройте регату и измените вводные, расписание или задачи. У роли и каждой задачи может быть несколько ответственных. Введите их Telegram-имена через запятую.
2. Сохраните изменения и откройте вкладку **Ссылки**. Отправьте команде общую ссылку. В режиме **Все участники** можно просматривать задачи. Чтобы отмечать выполнение, участник выбирает свой Telegram-ник. Галочки доступны у задач с его назначением, включая общие задачи. Выбор ника работает без входа через Telegram. Названия, описания, время и назначения редактируются в кабинете.
3. Сохраните мероприятие как шаблон. Откройте **Шаблоны** и создайте мероприятие на его основе. У новой копии будут свои ссылки, дата, назначения и статусы.

Ссылки с адресом `127.0.0.1` открываются только на компьютере с запущенным трекером. Для доступа с других устройств приложению нужен общий адрес. Вводные и Telegram-имена видны всем, у кого есть общая ссылка.

## Оформление

На телефоне нижняя панель переключает **Задачи**, **План**, **Команду** и **Важное**. Нажатие на название мероприятия также открывает **Важное**. На широком экране навигация расположена над содержимым.

На телефоне в **Задачах** выберите Telegram-ник и листайте карточки постов. В списке видны время, описание и ответственные. Галочка отмечает задачу выполненной и оставляет её на прежнем месте. Кнопка **SOS** под своим постом отправляет запрос помощи от этого поста. Выбранный ник запоминается в браузере для этого мероприятия.

Доска обновляется автоматически. Организатор может войти через меню **⋯**, чтобы открыть шаблоны и получать уведомления на открытой странице мероприятия. Запрос **SOS** показывает уведомление **Нужна помощь** на пять минут. Когда все задачи поста выполнены, появляется зелёное уведомление **Пост готов** на три минуты. Любое уведомление можно сразу закрыть крестиком.

**План** показывает расписание всей команды и текущее московское время. Текущий этап подсвечивается автоматически. Нажмите на этап, чтобы раскрыть его описание и задачи. Остальные задачи находятся в блоке «Задачи вне этапов».

## Обложка мероприятия

В редакторе откройте **Вводные → Обложка мероприятия** и выберите JPEG, PNG или WebP до 15 МБ. Трекер уменьшит изображение, сохранит его и подстроит кадр под размер шапки. Здесь же обложку можно заменить или удалить. Обложка относится к конкретному мероприятию.

## Импорт из JSON

В кабинете откройте **Импорт JSON**. Нажмите **Копировать промпт** и отправьте его нейросети вместе с описанием мероприятия. Вставьте полученный JSON в поле и нажмите **Создать из JSON**. Трекер создаст отдельное мероприятие и откроет его в редакторе. Чтобы проверить формат, воспользуйтесь [примером JSON](public/event-import-example.json) или [промптом](public/event-import-prompt.txt).
