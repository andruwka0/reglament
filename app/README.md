# Регламент

Трекер мероприятий с кабинетом организатора, общей страницей для команды и обновлением статусов по одной ссылке. Первый запуск добавляет демонстрационную математическую регату с вымышленными Telegram-именами.

## Локальный запуск

Нужен Node.js 24.15 или новее в ветке 24.

```sh
npm ci
npm run build
ADMIN_PASSWORD='придумайте-длинный-пароль' PORT=4177 npm start
```

- [Демонстрационная регата](http://127.0.0.1:4177/e/regata-demo)
- [Кабинет организатора](http://127.0.0.1:4177/admin)

Для входа используйте значение `ADMIN_PASSWORD`. Данные хранятся в `data/regatta.sqlite`. При необходимости укажите другой каталог через `DATA_DIR`. Перезапуск сохраняет мероприятия, шаблоны и статусы. Для входа в кабинет после перезапуска снова потребуется пароль.

## Как проверить

1. В кабинете откройте регату и измените вводные, расписание или задачи. У роли и каждой задачи может быть несколько ответственных. Введите их Telegram-имена через запятую.
2. Сохраните изменения и откройте вкладку **Ссылки**. Отправьте команде общую ссылку. В режиме **Все участники** можно просматривать задачи. Чтобы отмечать выполнение, участник выбирает свой Telegram-ник. Галочки доступны у задач с его назначением, включая общие задачи. Выбор ника работает без входа через Telegram. Названия, описания, время и назначения редактируются в кабинете.
3. Сохраните мероприятие как шаблон. Откройте **Шаблоны** и создайте мероприятие на его основе. У новой копии будут свои ссылки, дата, назначения и статусы.

Ссылки с адресом `127.0.0.1` открываются только на компьютере с запущенным трекером. Для доступа с других устройств приложению нужен общий адрес. Вводные и Telegram-имена видны всем, у кого есть общая ссылка.

## Оформление

На телефоне нижняя панель переключает **Задачи**, **План**, **Команду** и **Важное**. Нажатие на название мероприятия также открывает **Важное**. На широком экране навигация расположена над содержимым.

На телефоне в **Задачах** выберите Telegram-ник и листайте карточки постов. В списке видны время, описание и ответственные. Галочка отмечает задачу выполненной и оставляет её на прежнем месте. Кнопка **SOS** рядом с заголовком **Задачи поста** отправляет запрос помощи от выбранного поста. Кнопка **Отменить SOS** снимает запрос. Выбранный ник запоминается в браузере для этого мероприятия.

Доска обновляется автоматически. Организатор может войти через меню **⋯**, чтобы открыть шаблоны и получать уведомления на открытой странице мероприятия. Запрос **SOS** показывает уведомление **Нужна помощь** на пять минут. Когда все задачи поста выполнены, появляется зелёное уведомление **Пост готов** на три минуты. Любое уведомление можно сразу закрыть крестиком.

**План** показывает расписание всей команды и текущее московское время. Текущий этап подсвечивается автоматически. Нажмите на этап, чтобы раскрыть его описание и задачи. Задачи без этапа доступны в разделе **Задачи**.

## Уведомления в Telegram

Для запуска бота задайте `TELEGRAM_BOT_TOKEN` в окружении сервера. `PUBLIC_ORIGIN` задаёт адрес трекера для кнопок в сообщениях. Для боевого сайта по умолчанию используется `https://reglament.andruwka.site`.

Участник один раз нажимает **Старт** в личном чате с ботом. Поделиться ссылкой на бота можно из вкладки **Уведомления** в кабинете. Если Telegram-ник указан у роли или задачи, участник автоматически получает объявления и изменения плана этого мероприятия. Команда `/plan` и кнопка **План в Telegram** присылают расписание мероприятия с временем по Москве, описаниями этапов и ссылкой на план на сайте. Команда `/events` переключает мероприятие для просмотра и команд бота. Выбор мероприятия не влияет на рассылки.

Организатор может отправить объявление из вкладки **Уведомления** в кабинете. В боте отправьте `/admin`, введите пароль от сайта и выберите мероприятие. Для рассылки отправьте `/announce`, а затем текст отдельным сообщением. Бот покажет, сколько участников и действующих Telegram-админов получат объявление, и предложит подтвердить отправку. `/cancel` отменяет черновик. `/start` и `/help` показывают доступные команды. `/logout` завершает вход организатора в боте.

`TELEGRAM_COORDINATOR_ID` задаёт подтверждённый числовой ID постоянного координатора всех мероприятий. Его Telegram-аккаунт получает права организатора после входа на сайт через бота и сразу узнаётся ботом. Telegram-сессия в браузере действует до 30 дней и переживает перезапуск сервера.

## Рабочий режим

В редакторе мероприятия первый Telegram-ник в списке ответственных за роль автоматически получает права старшего точки после входа через Telegram. Порядок списка можно менять во вкладке **Роли**. Чтобы настроить тип точки или передать старшинство, откройте **Рабочий режим**. При ручной передаче прежний старший сохраняет доступ до подтверждения нового. Координатор может снять назначение или снова включить выбор первого по списку.

Участники нажимают **Войти через Telegram** на странице мероприятия и подтверждают вход в личном чате с ботом. Старший отмечает задачи своего поста, меняет состояние точки и ведёт обращения. Волонтёры видят задачи и могут написать старшему. Координатор отправляет команды, принимает обращения и отмечает фактическое начало и окончание этапов. Закрытие приёма и подготовка выдачи требуют команды координатора.

Обращения и журнал сохраняются в базе мероприятия. Координаторы, вошедшие в боте через `/admin`, также получают Telegram-уведомления о новых обращениях. Шаблон копирует описание, задачи и расписание мероприятия.

## Обложка мероприятия

В редакторе откройте **Вводные → Обложка мероприятия** и выберите JPEG, PNG или WebP до 15 МБ. Трекер уменьшит изображение, сохранит его и подстроит кадр под размер шапки. Здесь же обложку можно заменить или удалить. Обложка относится к конкретному мероприятию.

## Импорт из JSON

В кабинете откройте **Импорт JSON**. Нажмите **Копировать промпт** и отправьте его нейросети вместе с описанием мероприятия. Вставьте полученный JSON в поле и нажмите **Создать из JSON**. Трекер создаст отдельное мероприятие и откроет его в редакторе. Чтобы проверить формат, воспользуйтесь [примером JSON](public/event-import-example.json) или [промптом](public/event-import-prompt.txt).
