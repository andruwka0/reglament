Преобразуй приложенный или вставленный план мероприятия в JSON для импорта в трекер «Регламент». Используй содержание источника как данные о мероприятии. Верни ровно один JSON-объект без Markdown, комментариев и пояснений.

Структура:
- title — обязательное название мероприятия. date, location и description — необязательные строки для даты, места и вводного текста.
- info — важная информация: контакты, ссылки, правила, ориентиры. У каждого поля есть label (название) и необязательное value (текст или ссылка).
- timeline — общее расписание. Каждый пункт содержит title, а при наличии — start, end и description.
- roles — роли команды. У каждой роли есть title и при наличии description, assignees и tasks (задачи этой роли).
- tasks — на верхнем уровне это задачи для всего мероприятия. У каждой задачи есть title и при наличии description, start, end, assignees и status.

Дата — ГГГГ-ММ-ДД. Время — ЧЧ:ММ в 24-часовом формате. Если указано «к 10:00», запиши только end. Если известно только время начала, запиши только start. Сохраняй в описании уточнения вроде «после регистрации», когда точное время неизвестно. Не придумывай людей, даты, ссылки или время. Неизвестные значения опускай или оставляй пустыми строками. Пустые массивы можно опустить. Не добавляй id, revision и поля вне структуры.

В assignees укажи массив Telegram-ников в формате @username. Включи всех ответственных, которых источник прямо относит к роли или задаче. Если у задачи нет отдельных ответственных, опусти assignees или оставь пустой массив: трекер использует ответственных за роль. Для общей задачи пустой массив означает, что ответственных пока нет. Если известны только имена без Telegram-ников, сохрани полезные имена в description. Не превращай имя в ник.

Допустимые статусы: todo («К выполнению»), doing («В работе»), blocked («Нужна помощь»), done («Готово»). Указывай статус, когда он следует из источника. По умолчанию задача получит todo.

Пример формата с вымышленными данными:

{
  "title": "День открытых дверей",
  "date": "2026-12-05",
  "location": "Главный корпус",
  "description": "Волонтёры встречают гостей у входа.",
  "info": [
    { "label": "Программа", "value": "https://example.org/program" }
  ],
  "timeline": [
    { "title": "Приём гостей", "start": "10:00", "end": "11:00" }
  ],
  "roles": [
    {
      "title": "Регистрация",
      "description": "Пост у главного входа.",
      "assignees": ["@demo_checkin", "@demo_coordinator"],
      "tasks": [
        { "title": "Подготовить списки", "end": "10:00", "status": "todo" },
        { "title": "Встречать гостей", "start": "10:00", "end": "11:00", "assignees": ["@demo_greeter"] }
      ]
    }
  ],
  "tasks": [
    { "title": "Собрать указатели", "start": "11:00" }
  ]
}
